## 🧠 Minimax with Alpha-Beta Pruning

This repository includes an implementation of the **Minimax algorithm with Alpha-Beta pruning** in Python.

### Example

```python
values = [3, 5, 6, 9, 2, 0, -1, 4]

result = minimax(0, 0, True, values, MIN, MAX)

print("The optimal value is:", result)
```

### Output

```text
The optimal value is: 5
```
